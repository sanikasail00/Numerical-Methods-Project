# Numerical Methods and Applications

A menu-driven Python project implementing numerical methods from the subject **Numerical Methods and Applications**.

## Project Description

This project is a console-based Python application developed to demonstrate different numerical methods used for solving equations, interpolation problems, numerical integration, ordinary differential equations, boundary value problems, and partial differential equations.

The program provides a main menu from which the user can select any of the five modules. Each module contains three numerical methods, giving a total of **15 numerical methods**.

The program uses a menu-driven structure with Python's `match-case` statement. User inputs are taken through the console and the corresponding numerical method is executed.

---

## Modules and Methods

### Module 1 – Solution of Equations and Linear Systems

1. Fixed Point Iteration Method
2. Gauss-Jacobi
3. Gauss-Jordan

### Module 2 – Interpolation and Curve Fitting

1. Lagrange's Interpolation Method
2. Linear Fitting of Curve (Straight Line)
3. Lagrange's Inverse Interpolation Method

### Module 3 – Numerical Integration and Quadrature

1. Simpson's 1/3 Rule
2. Romberg's Integration
3. Newton's Backward Interpolation Formula

### Module 4 – Initial Value Problems for ODE

1. Adams-Bashforth Method
2. Modified Euler's Method (Heun)
3. Fourth-Order Runge-Kutta

### Module 5 – Boundary Value Problems and PDEs

1. Heat Equation – Explicit
2. Two-Point Linear BVP
3. Poisson Solver

## Features

- Simple console-based interface
- Main menu and module-wise submenus
- Uses Python `match-case`
- User-defined inputs for numerical problems
- Iterative methods with tolerance and iteration controls where applicable
- Function evaluation using mathematical expressions
- Displays approximate numerical solutions
- Covers 15 numerical methods from the syllabus
